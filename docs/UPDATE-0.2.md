# 0.2 · 驾驶与赛事呈现更新

## 问题定位与修复

1. **A/D 反向**：模型前方为 +Z，从车后向前看时，驾驶者右侧为局部 -X。旧输入把 D 直接映射为正向偏航，导致画面中的方向相反。现统一转换键盘、方向键、触屏和手柄输入：A 左、D 右；AI 保持自己的曲率坐标。
2. **转向范围**：按“更大转向角、更容易转急弯”的意图调整；实际转弯半径减小。玩家低速最大轮角从约 29° 提高到约 41°，转向响应加快，横向转弯限制放宽；高速仍有稳定限制。对手仍使用原有弯速策略。
3. **手刹短按**：旧版只在按住时增加 7 m/s² 减速。现加入至少 0.3 秒制动脉冲，手刹制动项为 32 m/s²，同时抑制油门；长按持续制动，松开后自动恢复。后轮出现轻微滑移、薄烟、渐隐胎痕与摩擦声。
4. **车内镜头**：原第二镜头在引擎盖附近，并非驾驶席。现新增独立三维座舱，含仪表台、空调口、A 柱、方向盘、数字速度/挡位与路线示意屏；相机固定在驾驶眼位并跟随车体，不再因相机追随延迟穿入车壳。内外层隔离避免外部玻璃、车顶和座椅挡住前方。三款车共用此座舱布局。

## 赛事呈现

- 右侧透明银色大名次数字、发光描边、轻扫描线与实时数据。
- 平均时速：从发车到冲线按模拟时间积分实际车速；暂停、倒计时和冲线后的表演驾驶不计入。复位罚时也不混入驾驶均速。
- 最高时速：该场比赛实际采样的最大车速。
- 超车数量：玩家从对手后方越过并领先 2 米计一次；回落超过 5 米才重新允许计数，避免并排抖动重复计数。复位重新建立基线，不产生虚假超车。
- 每次有效超车触发名次数字滑入/放大、亮度闪动与“超越 +N”提示，语音独立限频。
- 冲线即冻结玩家驾驶数据。先播放约 9 秒的车头跟拍、后轮/车尾近景和环绕镜头，可跳过；其后显示右侧透明玻璃结算卡，数据渐增，背景镜头继续环绕。
- 其他车手未完赛时保留“暂列”状态，待全部冲线后按含罚时总成绩更新最终排名。

## 验证

- `npm test`：10 项通过；包括三档难度八车完整两圈，无救援复位。
- `scripts/update-qa.mjs`：三款车内镜头正常，外部车壳层在车内视角中不可见；浏览器没有脚本错误。
- 短按空格实机脚本采样，在约 95 km/h 下约 0.3 秒降低约 31–37 km/h，后轮粒子正常产生。帧调度与当时油门状态会影响具体数值。
- 实际浏览器输入完成超车，名次从第 8 变为第 7，超车数 +1，动效触发。
- 完整比赛验证平均/最高时速、冲线冻结、连续变化的镜头位置、透明结算，以及 1280×720 布局。
