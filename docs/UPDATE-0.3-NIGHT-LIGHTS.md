# AFTERLIGHT 0.3 · 夜间照明与车灯

## 体验入口

在主界面点击“开始竞速”，于“赛道氛围”选择“暗夜 · 霓虹潮汐”。白天地图默认不点亮车灯；暗夜地图发车时玩家默认使用近光灯。

## 夜间赛道

- 金潮海岸保留同一条赛道几何，夜景由独立主题层切换。
- 路灯沿赛道分段布置，部分路段保持低照度，让明亮照明和深色海岸交替出现。
- 点光源会照亮路面、车辆和路侧设施；灯具使用暖橙与冷青两种色温。
- 路侧加入蓝色、粉色氛围标记，星空、月光和夜雾共同控制远景层次。

## 车辆灯光

比赛中按 `L` 循环切换：

1. 近光灯
2. 远光灯
3. 蓝红氛围灯
4. 关闭

对手车辆在暗夜中会以不同车漆、灯色、亮度和开关状态出场，约一半车辆关闭车灯，形成更自然的车队层次。白天地图的所有车辆初始关闭车灯。
