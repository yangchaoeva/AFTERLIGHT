# 五车车库与原创车辆更新

## 运行

双击项目根目录 `Start-Game.cmd`，或执行 `npm start`，访问 http://127.0.0.1:4180/ 。源码修改后执行 `npm run build`。开发使用 `npm run dev`。

首页点击“进入车库 / 选择车辆”。车辆卡片只预览；“驾驶此车”或 Enter 确认并打开现有赛事设置。返回 / Esc 放弃本次修改。左右方向键切换五辆有效车型。拖动旋转、滚轮缩放，镜头按钮恢复默认或查看前脸、轮组、尾部。触屏可拖动预览、横向滚动车卡并点击操作。已确认车型和每车车漆保存在本浏览器 localStorage。

## 实现

- 保留 AURORA GT、KASUMI R、VESPER X，新增 NIGHTSLASH 和 TEMPEST。第六格不可选择、不含参数，不计入五辆座驾。
- 夜刃：紧凑方正双门、六辐凹轮圈、圆形透镜灯与四圆尾灯、克制支架尾翼；灵活转向与渐进滑移。
- 雷暴：更长机盖、后移座舱、宽车肩、五辐轮圈及宽后胎、分段灯组、双侧矩形排气、整合尾唇；更强加速，较慢转向与较长制动距离。
- 新车使用独立开放座舱的曲面构造，前后甲板、车肩与带轮拱的侧壁连续采样；共享轮胎、材质和细节构造工具。无外部车辆 GLB、无游戏提取模型，使用现有 Three.js MIT 工具与项目环境资源。
- 车漆、玻璃、橡胶、金属、内饰和复合材料分开；座椅、仪表、中控、方向盘可见。轮辐/刹车盘滚动，卡钳只随前轮转向。实际光源延续近光、远光、氛围灯与关闭模式。
- `src/vehicle-catalog.js` 是车辆/物理/车库/性能/音色的共同数据源。碰撞尺寸、轴距、驾驶席视点及烟雾位置跟随车辆尺寸。
- 独立全屏实时车库复用现有 WebGLRenderer，每次只渲染一辆高精模型；卡片使用逐辆生成并缓存的真实模型缩略图。切车、退库释放独占几何体、材质和纹理。
- 性能信息由本游戏物理在平直路面计算；0–100 时间单位 s、100–0 距离单位 m、游戏极速 km/h、模拟质量 kg。不代表真实车测或马力。

## 质量边界

这是可驾驶的原创程序化 Demo 模型，尚未达到《极限竞速》量产车辆扫描/CAD及手工拓扑资产的精细度。近看仍有简化的板件转角、灯罩、轮胎花纹和内饰；复合材料仅区分材质，没有精细编织贴图。驾驶席使用匹配尺寸的独立渲染层，外部简化内饰与驾驶席仪表并非完全相同的资产。当前多角度未见明显大面积破面或悬浮轮组，但不声称对全部转向/镜头角度做了穷举穿模验证。

驾驶仍是街机运动模型，没有真实悬架、轮胎接地或传动仿真；性能数值只用于游戏内比较。触屏使用浏览器模拟验证，未进行真实手机硬件性能测试。帧率为展厅短时结果，不能推断三条赛道所有昼夜场景均为 60 FPS。声音功能与车型音色逻辑保留，未开展主观听感评测。
