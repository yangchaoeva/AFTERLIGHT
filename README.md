# 逐光 AFTERLIGHT · 三境竞速

**选一辆车，挑一条路，追上最后一束光。**

AFTERLIGHT 是一款免费、无需安装的原创 3D 浏览器赛车游戏。驾车穿过金色海岸、霓虹港城与高山弯道：和七位对手争夺名次，或独自挑战最快单圈。日落、暗夜或随机氛围，每次发车都有不同的光。

### [立即在线游玩 →](https://yangchaoeva.github.io/AFTERLIGHT/)

> 建议使用开启硬件加速、支持 WebGL 2 的最新版 Chrome 或 Edge。首次进入会加载和生成 3D 场景，稍等片刻即可开跑。

| 赛道 | 旅程 |
| --- | --- |
| **金潮海岸** | 2.55 公里海岸线，掠过灯塔、山坡长弯和跨海高架。 |
| **铬湾港城** | 4.77 公里港口与城区，穿过集装箱 S 弯、斜拉桥和仓库走廊。 |
| **岚脊天路** | 6.38 公里高山道路，挑战回头弯、红岩切坡和悬谷桥。 |

六辆座驾可在实时 3D 车库里选择、换色和鉴赏，其中包括五款原创参数化车型与可选的 Green Bug。比赛支持八车两圈竞速、单车计时挑战与三档对手难度。最佳成绩和赛事历史保存在当前浏览器；键盘、标准手柄和触屏均可驾驶。

**首次游玩**：进入车库选择车辆 → 点击「开始竞速」选择赛道和玩法 → 欣赏或跳过航拍 → 等待倒计时出发。欢迎在 [Issues](https://github.com/yangchaoeva/AFTERLIGHT/issues) 分享成绩、问题和建议。

## 在线发布

推送到 `main` 分支后，GitHub Actions 会自动运行测试、构建并发布到 GitHub Pages。首次发布需在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。在线地址为 <https://yangchaoeva.github.io/AFTERLIGHT/>。

以下保留完整操作、制作和验证记录，方便深入了解项目。

## 立即运行

Windows 双击 **Start-Game.cmd**。它会启动本地服务器并打开 `http://127.0.0.1:4180`。当前工作区已生成 `dist`，启动时不需要下载游戏素材。

需要 Node.js 20.19+ 或 22.12+；开发与验证环境为 Windows、Node.js 24、Chrome。使用支持 WebGL 2 并开启硬件加速的 Chrome / Edge。

也可在项目目录执行：

```powershell
npm ci
npm run build
npm start
```

开发模式：`npm run dev`。不要直接双击 `index.html`，ES 模块和音频需要本地 HTTP 服务。

## 首页与发车

首次打开默认展示铬湾港城，赛道顺序为港城、海岸、山地。所有可用按钮支持鼠标悬停放大、抬升、亮度与阴影反馈，按下时回弹；减少动态效果设置下关闭缩放。

八车使用双列错位发车与 14 米同列排距。AI 起步守住原车道，采用短反应时间和渐进油门，按前车速度与保险杠间距跟车；后续换道先检查旁侧及后车接近情况，并限制横向移动速度。保留真实碰撞反馈，玩家主动追尾或横切仍可能碰撞。

## 开赛航拍

三张地图每次开赛前播放约 15 秒航拍：完整路线俯瞰 → 沿线掠影 → 发车位。显示地图名称、赛道挑战等级、比赛模式、对手难度、长度和高差；Space / Enter / Esc 或右上角按钮跳过。开场不推进比赛时间或车辆运动，末段平滑落到实际座驾的第三人称追尾位置，再进入原有倒计时；跳过也保留短暂平滑过渡。暗夜航拍带临时冷色补光，结束后恢复赛道照明。

验证：`npm test`（41 项）；`node scripts/intro-qa.mjs` 检查三条赛道、自动结束/跳过、静止发车与页面异常。截图在 `artifacts/intro/`。

## 这一版包含什么

- 金潮海岸：2.55 公里海岸环线，山坡长弯、跨海高架、灯塔与沿岸植被。
- 铬湾港城：4.77 公里，高差 49 米，集装箱 S 弯、港口斜拉桥、城区连续转向与仓库走廊。
- 岚脊天路：6.38 公里，高差 260 米，山坡回头弯、红岩切坡、云杉林、拱形廊道、悬谷桥与山村。
- 开始竞速后选择赛道，可预览路线、高程、路宽与检查点数量；新赛道上坡减速、下坡加速。
- 五款原创参数化车辆：曙光 GT、雾刃 R、暮星 X、夜刃 NIGHTSLASH、雷暴 TEMPEST。各有动力与操控设定、轮组、灯具、玻璃与简化内饰。
- 八车两圈竞速，三档 AI 难度；单车一圈计时挑战。
- 真实输入控制的街机车辆运动、刹车、手刹滑移、平稳车身、边界和车间碰撞。
- 顺序检查点、圈数、名次、复位罚时、本地分赛道/昼夜/车型/模式/难度纪录。
- 独立汽车鉴赏场景，环绕/前脸/轮组/尾部镜头、原厂色和六种通用车漆与 GLB 导出。
- 日落 HDR 天空、程序化海水、物理材质、阴影与本地字体。
- 本地中文合成播报、合成引擎/风噪/轮胎声，可独立关闭语音或全部声音。
- 键盘、标准手柄映射及触屏按钮；高/标准/流畅画质。

## 操作

| 按键 | 功能 |
| --- | --- |
| W / ↑ | 油门 |
| S / ↓ | 刹车 |
| A D / ← → | 转向 |
| 空格 | 强手刹，短按至少触发 0.3 秒制动，后轮产生薄烟和胎痕 |
| C | 追尾 / 驾驶席第一人称 / 远景镜头 |
| L | 近灯 / 远灯 / 蓝红氛围灯 / 关闭 |
| R | 复位，追加 3 秒罚时 |
| Esc | 暂停 / 继续 |
| M | 静音切换 |
| 鉴赏界面拖动 / 滚轮 | 环绕 / 缩放 |

手柄：左摇杆转向、RT 油门、LT 刹车、A 手刹、Y 镜头、X 复位、Start 暂停。当前为自动挡、前进驾驶；翻车和倒车系统尚未实现。

## 模型文件

`src/vehicle.js` 是三款车辆的可编辑建模源，`models/AFTERLIGHT-*.glb` 是导出的独立模型。GLB 可以导入 Blender 等支持 glTF 的三维软件，车辆不是图片贴板。鉴赏界面也能导出当前车漆版本。

这是程序化原创模型 Demo，尚未达到 AAA 汽车模型的曲面、拓扑与细节质量。0.2 加入独立驾驶席座舱视角，包含仪表台、同步仪表与方向盘，并在此镜头中隔离外部车壳。三款车暂时共用同一套座舱布局；没有软体损坏、轮胎变形或真实动力总成模拟。

## 验证

`npm test` 验证八车两圈、三档难度、顺序检查点、逆向重复过线、单圈计时、罚时和刹车复位。

0.2 另增加转向符号、转向范围、短按手刹、时长加权均速、超车防抖、复位排除与冲线冻结测试。`node scripts/update-qa.mjs` 验证三款车内视角、短按手刹烟雾、超车动效、完整比赛、九秒运镜和透明结算。

`node scripts/acceptance.mjs` 在运行中的开发服务器 `5173` 上执行浏览器验收，包括模型导出、驾驶输入、暂停计时、复位罚时、完整竞速/计时和设置持久化。测试使用本机 Chrome 的无界面模式；路径在脚本中可修改。快速推进仅在开发模式且 URL 含 `?qa` 时提供，生产构建没有此入口。

`node scripts/circuits-qa.mjs` 验证三赛道切换、两圈全员完赛、昼夜与车内灯光、鉴赏返回及移动端选图。截图和报告输出到 `artifacts/circuits/`。

## 当前边界

- 画面目标是精细的原创独立游戏 Demo；不代表《地平线》或《极品飞车》的画质与物理完成度。
- 全赛道使用固定干燥天气。没有开放世界、警察、交通车或联网。
- 赛道边界采用道路横向约束；车间碰撞采用简化车体模型。
- 对手通过前瞻走线、弯道速度和局部避让驾驶。比赛仍需要真人试玩调校。
- 帧率取决于硬件；无界面测试结果不能代替目标玩家电脑上的性能验收。
- 播报为 Windows 本地 TTS 合成，非真人录音；引擎是原创合成音效，非实车采样。
- 资源来源与许可见 `docs/THIRD_PARTY.md`。

后续可继续精修车辆曲面、景观材质与驾驶反馈；山路采用贴地的街机物理，没有腾空、悬挂或天气模拟。新场景首次进入会进行本地建模与材质编译，随后切换使用缓存。
